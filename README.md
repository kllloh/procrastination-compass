# Procrastination Compass

A fun, single-page self-diagnostic for Australian actuarial students. Answer 12 quick questions and find out which of six procrastination styles you lean toward — Perfectionist, Avoider, Dreamer, Crisis-Maker, Defier, or Overdoer — then get strategies built for your pattern, framed around accredited units, Actuaries Institute exams, and cadetship applications.

Based loosely on procrastination research by Linda Sapadin and Piers Steel. Not a clinical assessment — just a mirror with jokes.

## Running it

It's a single static `index.html` with no build step and no dependencies beyond two Google Fonts. Open the file directly in a browser, or serve the folder with any static file server.

## Deploying

This repo is set up to work as-is with GitHub Pages: enable Pages in the repo settings, pointing at the `main` branch root, and `index.html` will be served directly.
